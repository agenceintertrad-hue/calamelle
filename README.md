# Calamelle — page « Prochainement »

Hero statique en HTML, CSS et JavaScript vanilla, prêt à être publié sur Vercel.

## Prévisualisation locale

Ouvrez `index.html` directement dans un navigateur ou lancez un serveur statique :

```bash
python -m http.server 8000
```

## Déploiement

Importez le dépôt GitHub dans Vercel. Aucun build ni variable d’environnement n’est nécessaire ; le dossier racine est directement publiable.

Le formulaire est actuellement une interaction de démonstration côté client. Branchez-le à votre outil de collecte d’e-mails avant la mise en production.
